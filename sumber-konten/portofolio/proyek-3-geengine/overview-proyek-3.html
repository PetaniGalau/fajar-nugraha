Implementasi Google Earth Engine API untuk pengolahan Big Data citra satelit Sentinel-2 dan Landsat guna mendukung presisi pengelolaan wilayah DAS secara real-time.

Metodologi & Inovasi

Sebagai bagian dari riset pascasarjana saya di IPB University, saya mengembangkan platform ini untuk memangkas waktu analisis spasial dalam riset mengenai Kinerja Sub-DAS Tanralili.

Sistem ini menggunakan Python Flask untuk menghubungkan permintaan parameter pengguna langsung ke infrastruktur cloud processing Google. Platform ini mengotomatiskan langkah cloud masking dan kalkulasi indeks vegetasi secara masif tanpa membebani komputasi lokal.

Python Flask Google Earth Engine Koyeb Cloud Leaflet.js

Fitur Unggulan

  • 01

    Cloud-Based Processing: Komputasi di server Google, memungkinkan analisis Big Data di perangkat apa pun tanpa lag.

  • 02

    Dinamis AOI: Penentuan wilayah riset melalui alat gambar poligon interaktif untuk ekstraksi data spesikan lokasi.

  • 03

    Otomasi Indeks: Perhitungan instan NDVI, EVI, dan NDWI untuk pemantauan kesehatan vegetasi dan sumber daya air.

Aplikasi WebGIS Interaktif

LontaraGeo Engine: Eksplorasi pengolahan citra satelit secara langsung di browser.
