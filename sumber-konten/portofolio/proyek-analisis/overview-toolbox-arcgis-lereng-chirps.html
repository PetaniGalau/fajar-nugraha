GIS Automation & Geoprocessing

ArcGIS Python Toolbox

Pengembangan toolbox pada ArcGIS 10.8 untuk membantu klasifikasi lereng dari DEM dan pengolahan curah hujan CHIRPS melalui antarmuka parameter geoprocessing.

Ringkasan proyek

Dua alur pengolahan dikemas dalam toolbox: Klasifikasi Lereng + MMU Iteratif dan CHIRPS Monthly Aggregation BufferIDW. Pengguna memilih input, parameter, serta lokasi keluaran melalui form, lalu menjalankan proses dari lingkungan ArcGIS.

Kapabilitas

Klasifikasi lereng

Menggunakan DEM sebagai input untuk menghasilkan raster lereng dalam persen dan poligon kelas lereng. Form menyediakan pilihan klasifikasi dan skala peta.

MMU iteratif

Tool klasifikasi lereng mencakup MMU iteratif (Minimum Mapping Unit). Pengaturan klasifikasi dan skala peta tersedia pada antarmuka yang terdokumentasi.

Pengolahan CHIRPS

Tool menerima folder data CHIRPS bulanan dan AOI. Antarmuka menyediakan mode output, resolusi IDW, serta lokasi keluaran total dan rata-rata.

Alur kerja

  1. Menyiapkan DEM untuk lereng, atau folder CHIRPS bulanan dan batas AOI untuk curah hujan.
  2. Membuka tool yang sesuai di ArcGIS 10.8 dan mengisi parameter input serta lokasi output.
  3. Pada tool lereng, memilih klasifikasi dan skala peta sebelum menjalankan proses klasifikasi dan MMU iteratif.
  4. Pada tool CHIRPS, menentukan mode keluaran dan resolusi IDW; contoh dokumentasi menggunakan 12 berkas bulanan dengan mode TOTAL.
  5. Memeriksa keluaran raster lereng, poligon kelas lereng, atau raster curah hujan tahunan di ArcGIS.

Output & hasil

  • Lereng.tif: raster lereng dalam persen.
  • Kelas_Lereng.shp: poligon kelas lereng.
  • Raster curah hujan tahunan dari agregasi CHIRPS bulanan, dengan contoh keluaran Curah_Hujan.tif.
  • Antarmuka parameter untuk menjalankan kedua alur pengolahan dari ArcGIS.

Dokumentasi menunjukkan penggunaan pada ArcGIS 10.8. Kompatibilitas dengan versi ArcGIS lain dan besarnya penghematan waktu belum diuji dalam materi sumber.
